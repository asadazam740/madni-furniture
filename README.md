# Luxe Furniture

A modern React furniture website with header, product catalog, and footer components.

## Features

- Responsive header with navigation
- Product catalog with 6 furniture items
- Modern footer with contact info
- Clean, professional design

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
